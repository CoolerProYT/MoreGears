# Getting started

More Gears adds six tiers of tools, weapons and armor to Minecraft, plus the ores, alloys and upgrade templates you need to make them. Each tier sits somewhere on the vanilla ladder, and the last two go well beyond netherite.

## Install

1. Install [NeoForge](https://neoforged.net/), or [Fabric](https://fabricmc.net/) with [Fabric API](https://modrinth.com/mod/fabric-api).
2. Download the More Gears file for your Minecraft version and loader from [CurseForge](https://www.curseforge.com/minecraft/mc-mods/more-gears) or [Modrinth](https://modrinth.com/mod/more-gears).
3. Put the `.jar` in your `mods` folder and start the game.
4. Optional: add [JEI](https://modrinth.com/mod/jei) or [REI](https://modrinth.com/mod/rei) to look up every recipe in game, including Alloy Smelter recipes.

## Versions

<VersionTable />

This wiki follows the latest version. Older versions may be missing newer items like spears and maces. Bows and arrows need Minecraft 1.21.4 or later.

::: info Copper gear
Minecraft now has its own copper tools and armor, so More Gears no longer adds them. It keeps the copper bow and copper arrows, and makes a full set of vanilla copper armor block lightning.
:::

## Where to start

A typical playthrough goes like this:

1. **Mine tin and ruby** while you look for iron. Both generate in stone and deepslate. See [Ore generation](./ores).
2. **Build an [Alloy Smelter](./alloy-smelter)** from two furnaces, deepslate and gunpowder.

   <RecipeCard id="alloy_smelter" />

3. **Alloy [bronze](./materials#bronze-ingot)** from copper and tin, then **[steel](./materials#steel-ingot)** from iron and coal. Each makes a full set of gear.
4. **Craft ruby gear**, which sits just below diamond.
5. **Go to the Nether for titanium.** Titanium ore is rare, like ancient debris. Use it with a [Titanium Upgrade Smithing Template](./smithing-templates) to turn netherite gear into titanium.
6. **Go to the End for enderite**, the top tier. Enderite gear never breaks.

For every item side by side, see [Tiers](/gear/tiers).
