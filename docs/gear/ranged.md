# Bows & arrows

Every tier, copper included, has its own bow, crossbow and arrows. Bows and crossbows fire any arrow, vanilla or modded. When you draw a bow with a More Gears arrow, it shows that arrow's colour.

<GearStats group="ranged" />

::: tip Mix and match
Arrow damage and bow durability don't depend on each other. An enderite arrow does the same damage from a copper bow as from an enderite bow, so a cheap bow with strong arrows works fine.
:::

Each arrow recipe makes **6 arrows**.

## Crossbows <Badge type="tip" text="26.3+" />

Every tier that has a bow also has a crossbow, with the same durability as that tier's bow. They behave like the vanilla crossbow — load a shot, keep it loaded, and fire when you want — and take the same arrows the bows do, plus firework rockets. Damage still comes from the arrow, so the tier only changes how long the crossbow lasts.

Each one is crafted like a vanilla crossbow with the tier's ingot in place of the iron.
