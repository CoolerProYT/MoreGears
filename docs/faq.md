# FAQ

## Where did copper tools and armor go?

Minecraft added its own copper tools and armor, so More Gears removed its copper versions to avoid duplicates. The copper bow and copper arrows are still here, and a full set of vanilla copper armor now makes you [immune to lightning](/gear/special-effects#copper).

## I can't find the new ores in my world

Ores only generate in chunks that haven't been generated yet. In an existing world, explore somewhere new. Titanium is rare by design, so blast mine for it the way you would for ancient debris. See [Ore generation](/guide/ores).

## Does it need to be installed on the server?

Yes. Install it on the server and on every client that joins.

## How do I repair the gear?

Use an anvil with the tier's material: a bronze ingot for bronze, a ruby for ruby, and so on. Enderite gear never breaks, so it never needs repairs. The mending enchantment works too.

## Can I see recipes in game?

Yes. With [JEI](https://modrinth.com/mod/jei) or [REI](https://modrinth.com/mod/rei) installed, every recipe shows up, including a separate Alloy Smelting category.

## Can I change the recipes?

Yes. All recipes are data-driven, so a datapack can override or add to them. The Alloy Smelter uses its own recipe type, `moregears:alloy_smelting`. See [Datapack recipes](/guide/alloy-smelter#datapack-recipes).

## The Alloy Smelter isn't doing anything

It needs both ingredients, energy, and room in the output slot. Check the energy bar on the left. If it's empty, put fuel in the slot with the lightning bolt, or connect an energy cable. See [Alloy Smelter](/guide/alloy-smelter).

## I found a bug

Please [open an issue on GitHub](https://github.com/CoolerProYT/MoreGears/issues) or report it on [Discord](https://discord.com/invite/hvFfqsqQm8). Include your Minecraft version, your loader, and the More Gears version.
